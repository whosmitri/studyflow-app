# 🌱 StudyFlow

StudyFlow is a web application created to help students organize their study goals in a simple, visual, and intuitive way.

## 💡 About the Project
The project was created during Lesson 01 of the Software Engineering with AI Immersion - Dev in the AI Era, using Google AI Studio to support the conception and implementation of the application.

Before moving on to the code, the idea was structured around a problem, functional requirements, and testing criteria.

## ✨ Features
* 📝 Create study goals.
* 👀 View registered goals.
* ✏️ Edit goal information.
* 🗑️ Delete goals after confirmation.
* 📅 Set deadlines and statuses.
* 📊 View the number of goals.
* 💾 Persist data using `localStorage`.
* 📱 Use a responsive interface.

## 🌟 How Does It Work?
1. Create a goal with a title and description.
2. Set a deadline and a status.
3. View registered goals.
4. Update information whenever necessary.
5. Delete goals after confirmation.

## 🔎 Development Process
* **Step 1 - Ideation:** exploring possibilities for solving a study organization problem.
* **Step 2 - Requirements:** defining the target audience, expected features, and acceptance criteria before generating the code.
* **Step 3 - Implementation:** building the application based on the defined requirements.
