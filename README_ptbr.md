# 🌱 StudyFlow

O StudyFlow é uma aplicação web criada para ajudar estudantes a organizar seus objetivos de estudo de maneira simples, visual e intuitiva.

## 💡 Sobre o projeto
O projeto nasceu durante a Imersão Engenharia de Software com IA - Dev na Era da IA, na Aula 01, utilizando o Google AI Studio como apoio na concepção e implementação da aplicação.

Antes de partir para o código, a proposta foi estruturada a partir de um problema, requisitos funcionais e critérios de teste.

## ✨ Funcionalidades
* 📝 Cadastrar objetivos de estudo.
* 👀 Visualizar objetivos cadastrados.
* ✏️ Editar informações dos objetivos.
* 🗑️ Excluir objetivos após confirmação.
* 📅 Definir prazos e status.
* 📊 Visualizar a quantidade de objetivos.
* 💾 Persistir os dados no `localStorage`.
* 📱 Utilizar uma interface responsiva.

## 🌟 Como funciona?
1. Cadastre um objetivo com título e descrição.
2. Defina um prazo e um status.
3. Consulte os objetivos cadastrados.
4. Atualize informações quando necessário.
5. Exclua objetivos mediante confirmação.

## 🔎 Processo de desenvolvimento
* **Etapa 1 - Ideação:** exploração de possibilidades para resolver um problema de organização dos estudos.
* **Etapa 2 - Requisitos:** definição do público, das funcionalidades esperadas e dos critérios de aceitação antes da geração do código.
* **Etapa 3 - Implementação:** construção da aplicação a partir dos requisitos definidos.

## ⚙️ Requisitos funcionais
| ID | Nome |
| - | - |
| RF01 | Cadastrar um objetivo. |
| RF02 | Listar os objetivos. |
| RF03 | Editar um objetivo existente. |
| RF04 | Excluir um objetivo após confirmação. |
| RF05 | Informar título, descrição, prazo e status. |
| RF06 | Exibir a quantidade de objetivos. |
| RF07 | Preservar os dados após atualizar a página. |
